# Workflow: graphify

Follow the graphify skill to run the full pipeline or query the graph:
- Full build: `/graphify .`
- Incremental update: `graphify update .`
- Query codebase: `graphify query "<question>"`
- Trace path between components: `graphify path "<A>" "<B>"`
- Explain node: `graphify explain "<node>"`
